Kaise kaam karta hai

Char steps. Patient ko kuch naya seekhna nahi — bas clinic ke number par call karni hai.

1

Call aati hai

Patient clinic ke number par call karta hai. AI greeting + recording-consent line bolta hai, aur patient ki bhasha (Hindi / English / Hinglish) follow karta hai.

2

Slot check hota hai

Naam, mobile, doctor aur din–time lekar system live slot check karta hai. Manga slot full ho to 2 sabse paas ke alternatives offer hote hain. Slot ka faisla hamesha deterministic code + database karta hai — LLM kabhi slot decide nahi karta.

3

Confirm-back, phir hold

AI poora confirm-back padhta hai — naam, din, samay, doctor. Patient “haan” bole tabhi booking aage badhti hai. Booking amount on ho to slot 15 minute hold hota hai aur WhatsApp par UPI payment link jata hai.

4

Confirmed + WhatsApp

Payment verify hote hi booking CONFIRMED hoti hai, token number milta hai, patient ko confirmation aur doctor + reception ko structured WhatsApp summary jata hai. Roz subah aaj ki poori list ka daily digest bhi jata hai.

Ek booking, shuru se aakhir tak

Ye ek honest product mock hai — simulated demo call ki transcript, asli clinic ki nahi. Demo data saaf taur par DEMO likha hai.

  • Refundable booking amount (₹100): aayenge to visit fees mein adjust, time par cancel (4 ghante pehle) par poora refund, bina bataye nahi aayenge to forfeit. Clinic-side cancel par hamesha poora refund.
  • Reschedule: amount nayi booking par carry-forward — dobara payment nahi.
  • No-UPI exception: jo patient UPI se pay na kar paaye, reception policy ke hisaab se manually confirm kar sakti hai — patient ke “maine pay kar diya” bolne se booking confirm nahi hoti.
  • Reminder par cancel: reminder par time par cancel kare to poora refund — forfeit kabhi nahi.

Jo product mein aaj sach mein hai

Har feature neeche PRD (v1.1) ke requirement se juda hai — aur automated tests se cover hai.

FR-01 – FR-05

Voice booking, confirm-back ke saath

Greeting, recording consent, naam–mobile–doctor–reason collect, live slot check, double confirm-back. Confirm ke bina koi booking save nahi hoti.

FR-04 / FR-06

Deterministic slot engine

Doctor-wise weekly schedule, breaks, holidays. Ek hi slot par do bookings database constraint se reject hoti hain. Full slot par hamesha 2 alternatives.

FR-26

Refundable booking amount

₹50 / ₹100 ya custom, per clinic / specialty / appointment type. 15-min hold, UPI link, webhook verify ke baad hi CONFIRMED. Adjust / refund / forfeit ke niyam code mein fixed hain.

FR-11 / FR-12 / FR-13

WhatsApp summary + daily digest

Har booking / cancel / reschedule par doctor + reception ko structured summary, patient ko confirmation with token, roz clinic khulne se 30 min pehle aaj ki list.

FR-14 / FR-19

Reminders + callback queue

Appointment se pehle (clinic-configured, default 2 ghante) WhatsApp reminder — opt-out kaam karta hai. Human chahiye ho to callback ticket, reception “done” mark karti hai.

FR-09 / FR-10

Safety, pehle

Emergency signals par booking rukti hai, emergency script + clinic alert. Medical advice par fixed deflection — dawai / diagnosis kabhi nahi. “Insaan se baat karni hai” par human handoff.

FR-16 / FR-17

Returning patient + config panel

Number se purana patient pehchana jata hai — naam dobara nahi poochha jata. Doctors, timings, fees text, greeting, WhatsApp numbers — sab bina code ke config se badalte hain.

FR-20 / FR-21 / FR-25

Manual entry + templates

Reception khud bhi usi register mein walk-in entry daal sakti hai. Multi-doctor routing naam / speciality se. Specialty templates: General, Dental, Dermatology, Paediatrics, Physiotherapy, Custom.

FR-23 / FR-18

Multi-tenant SaaS + admin

Har clinic ka alag workspace, login, number aur data — cross-tenant access 404 deta hai. Platform admin ko saari clinics, failures aur usage ek screen par dikhte hain.

Pricing — abhi hypothesis, final nahi

Pilot ke pehle 7 din ke asal per-call cost (telephony + STT/TTS + LLM + WhatsApp + hosting) se validate hone ke baad hi price lock hoga. Cost zyada nikli to pehle plan ki call limit / included minutes adjust hongi, price umeed par nahi badhega. Abhi koi payment button live nahi hai — payment demo mode mein hai.

FAQ

Kya ye medical advice ya diagnosis dega?

Nahi — kabhi nahi. “Kaunsi dawa loon?” ya “Ye serious hai?” par agent ek fixed deflection bolta hai aur appointment / reception ki taraf le jata hai. Emergency signals par booking rukti hai aur emergency script + clinic alert jata hai.

Real call kab se chalegi? Abhi kya demo hai?

Abhi demo mode hai: simulated call, simulated payment link aur simulated WhatsApp outbox end-to-end chalte hain, lekin koi real phone call, WhatsApp message ya rupee nahi chalta. Real pilot ke liye chahiye: telephony vendor trial + virtual number, WhatsApp BSP account + approved templates, Groq API key, Cashfree app (prod keys) aur Postgres/Redis URLs.

Pilot clinic kaunsi hogi?

Pilot specialty General / GP decide hai. Pilot clinic ka naam aur doctor abhi open hai (Open Decision D1) — demo mein sirf “Care Plus Clinic — DEMO” / “Dr. Sharma (DEMO)” placeholder hai, wo asli clinic nahi hai.

Ek clinic ka data doosri clinic dekh sakti hai?

Nahi. Har table mein tenant_id mandatory hai, har query tenant-scoped hai, aur cross-tenant access 404 deta hai — iske liye dedicated tests hain.

Clinic apna data export kar sakti hai?

Haan — dashboard / API se appointments ka CSV export milta hai, sirf apne tenant ka, bina support ko bole.

Booking amount kaise kaam karta hai?

Clinic amount ON/OFF, ₹50 / ₹100 ya custom set karti hai. Slot 15 minute hold hota hai, UPI link WhatsApp par jata hai, payment verify hote hi CONFIRMED + token. Visit par amount fees mein adjust, time par cancel par poora refund, clinic-side cancel par hamesha poora refund, no-show par forfeit.
